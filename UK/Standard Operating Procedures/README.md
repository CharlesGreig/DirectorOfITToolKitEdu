## Standard Operating Procedures

A list of generic standard operating procedures which can form the basis of SOPs to help a Director of IT get up and running asap and hopefully lighten the load of generating these documents.

They can be for anything really, I will break this down in a way that makes as much sense to me as I can into folders.\

Even where the actual SOP would be too specific for a location to make a generic version valuable, I might just put a placeholder file in here so that we can agree that perhaps we SHOULD have a SOP for that process.
