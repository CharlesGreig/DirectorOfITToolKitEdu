#Password Reset

Open Active Directory Users and Computers

Select your forest from the left hand pane

Right click and select 'find'

Ensure that Users and Groups is selected

Put the username of the user that you want to reset the password into and press find.

When the user appears in the list, ensure that this user is the correct one.

Verify that the user requesting the password reset is in fact the user they claim to be ( eg, search on the MIS to find DOB or first line of address + Photo )

Change password and tick 'reset on next login' box

Close AD Users and Computers
